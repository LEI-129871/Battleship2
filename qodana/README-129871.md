# Qodana Quality Gate: Large Class (129871 - <David Sousa>)

Cheiro escolhido: **Large Class** (Fowler).
No livro *Object-Oriented Metrics in Practice* (Lanza e Marinescu), o equivalente quantitativo é a **God Class** (secção 5.3, pp. 80-81).

## 1. Tabela de mapeamento

Estratégia do livro (God Class): `ATFD > FEW` **AND** `WMC ≥ VERY HIGH` **AND** `TCC < ONE THIRD`.
Limiares de partida derivados do livro (Java): WMC muito alto = 47 e NOM muito alto = 15 (Tabela 2.2, p. 16), FEW = 2 a 5 (Tabela 2.4, p. 18) e TCC < 0,33 (Tabela 2.3, p. 17).

| Cheiro (Fowler) | Inspeção no IDE | ID da inspeção | Métrica / limiar usado (`m_limit`) | Valor por omissão no IDE | Limitações |
|---|---|---|---|---|---|
| Large Class (≈ God Class) | Class with too many methods | `MethodCount` | nº de métodos (NOM) > 15 | 20 | Conta métodos e não a complexidade nem a coesão; limiar absoluto, não relativo ao sistema |
| | Overly complex class | `ClassComplexity` | WMC > 47 | 80 | Limiar absoluto, não estatístico |
| | (sem inspeção equivalente) | n/a | ATFD | n/a | Não existe inspeção para o acesso a atributos de outras classes |
| | (sem inspeção equivalente) | n/a | TCC | n/a | Não existe inspeção para a coesão da classe |
| | todas | n/a | n/a | n/a | Sem AND: cada inspeção dispara sozinha, o cruzamento tem de ser feito à mão |
